# Tic-Tac-Toe

Status: Completed

## Overview
Theme-rich Tic Tac Toe built with Streamlit. Play a five-round match, switch arenas, and enjoy animated win popups.

## Features
- Five-round match scoring with draw tracking
- Arena selector with visual spotlight preview
- Animated round/match win popups
- Responsive layout tuned for mobile and desktop

## Run locally
1. Create and activate a virtual environment.
2. Install dependencies:
	```
	pip install -r requirements.txt
	```
3. Start the app:
	```
	streamlit run app.py
	```

## Notes
- Arena visuals pull from hosted images and textures.
- The UI theme adapts to the selected arena.
